How we keep the rules right

Scheme rules change often. Every scheme links to its official page and shows the date we last checked it. The rules are stored as data, so a new limit is one number to change, with no code. Any scheme not checked for 90 days is flagged for re-checking.

Have the official pages changed?

When we check a scheme, we keep a copy of the text of its official page. This compares today's page with that copy, so we know which schemes need a fresh check.
